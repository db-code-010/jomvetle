# Jomvetle

A daily guessing game: is each character taller or shorter than Jomvet, a fluffy dog in a brown fedora who stands 21.5 cm tall? Tap whichever one you think is taller.

- **Daily**: the same 10 characters for everyone each day, with a shareable result grid.
- **Endless**: random characters; keep your streak going.
- **Catalogue**: every character and height, searchable.

The whole game is a single `index.html` file with every image built in, so it runs with no server or build step.
